# Entrance sounds

Four mono, 16-bit PCM WAV files at 44.1 kHz accompany the stop-motion entrances.

| File | Entrance | Duration | Original Kenney sound |
|---|---|---|---|
| `unfurl.wav` | Unfurl | 0.67 s | card-slide-8 |
| `snap.wav` | Snap | 0.40 s | card-place-2 |
| `slap.wav` | Slap | 0.60 s | card-place-4 |
| `slide.wav` | Slide | 0.67 s | card-shove-3 |

These sounds come from Kenney's Casino Audio pack and are released under CC0. See [LICENSE-Kenney.txt](LICENSE-Kenney.txt) for the original notice.

In a video editor, align the matching sound with the entrance's first frame. The preview and video exporter load these files automatically.
