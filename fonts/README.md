# Bundled font

`InkSerif.woff2` is a GB2312 subset of Source Han Serif Medium, renamed **InkSerif SC**. The renderer registers it as `InkSerif` for browser and canvas use.

The font is distributed under the SIL Open Font License 1.1. Keep [OFL-SourceHanSerif.txt](OFL-SourceHanSerif.txt) with the font when redistributing it.

To rebuild the subset, see [the font build script](../tools/build-fonts.py). Original font files are local build inputs and are excluded from this repository.
